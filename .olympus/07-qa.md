## Defects found but left alone on desktop (desktop had to stay unchanged)

1. **Section headings are 16 px on desktop too.** `SectionHeader` runs `text-section-title` through
   `cn()`; tailwind-merge treats it as a text colour that clashes with `text-ink`/`text-primary-foreground`
   and drops it. Phones get the ramp back from `mobile.css`; the real fix is a `twMerge` config entry
   (or passing the size class outside `cn`).
2. **University pages scroll sideways on desktop** (scrollWidth 1680 at 1280): the `1fr` grid track grows to
   the thumbnail strip. Phones use `minmax(0,1fr)`; the same at `lg` would fix desktop.
